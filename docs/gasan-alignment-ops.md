# Gasan 7F 정합 운영 절차 — 시작점 2클릭 vs 대응점 4개

- 작성일: 2026-09-15
- 대상: `upload_1781521406685` ↔ `models/Gasan_7F` (같은 층, as-designed ≠ as-built)
- 화면: `/coverage` (실적 evidence) · `/coplay?upload=upload_1781521406685` (경로 시각 확인)
- 관련: `docs/commercial-license-stack-prd.md`, `docs/model-coverage-webview-prd.md`

## 권고 (이 업로드)

**일상은 시작점 2클릭(위치+방향) → 후보 미리보기 → 명시 저장.**  
자동이 red/HOLD이거나 경로가 눈으로 어긋나면 **대응점 4~6개로 승격**한다.

이유: 이 영상은 천장 지향(점군 82%가 카메라 위), 문이 없고, 배관이 반복된다. 영상-only 전역 확정은 불변식이 금지한다. 시작점 2클릭이 yaw를 가르는 최소 힌트다. 대응점 4개는 더 정확하지만 점군에서 같은 물리점을 찍기 어렵다.

| | 시작점 지정 (2클릭) | 대응점 (4~6개) |
|---|---|---|
| 시간 | 1~2분 | 5~15분 |
| 잠그는 것 | 위치 구역 + yaw. 스케일은 자동 탐색 | 위치·회전·스케일 한 번에 (Sim3) |
| 품질 게이트 | 후보 미리보기 후 사람 저장 | green RMSE ≤ 0.10 m / yellow ≤ 0.25 m |
| 이 영상에 맞음 | **1순위** | 자동이 틀릴 때 **2순위** |
| coverage 분석 | 저장된 정합이 green/yellow여야 함. red면 observed 금지 | 4개 미만이면 분석 차단 |

`/coplay`의 **위치 지정**은 경로를 손으로 밀고 돌리는 시각 보정이다. coverage 실적 게이트와는 별 트랙이다. 실적 등록은 `/coverage`에서 정합을 저장한 뒤에만 한다.

## A. 시작점 지정 (실무 기본)

화면 왼쪽 **자동 정합 후보**.

1. **시작점 지정** 클릭 (버튼이 `시작점/방향 클릭...`으로 바뀜)
2. 모델에서 **① 촬영 시작 위치** 클릭 (배관·천장 카세트 등 눈에 보이는 표면)
3. **② 걸어간 방향**(배관 진행 방향)으로, 시작점과 **0.3 m 이상** 떨어진 곳을 한 번 더 클릭
4. 시스템이 자동 배치를 돌린다. 후보가 점군과 겹치는지 미리보기
5. 맞으면 후보를 **명시 저장** (미리보기만으로 coverage를 돌리지 않음)
6. 품질이 green/yellow이면 상단 **coverage 분석**
7. 객체별 `observed` / `likely_observed` / `uncertain` / `not_observed` 확인 후 **검수 기록**에서 사람 확정

실패 시:

- `모델 표면(배관)을 클릭하세요` → 외벽 SXX가 가리면 모델 필터로 내부를 보이게
- `후보 없음` → B로 승격
- 여러 후보가 비슷하면 **저장하지 않음** (HOLD가 정상)

## B. 대응점 4~6개 (정확 잠금)

화면 왼쪽 **수동 정합 입력**. 운영 기준은 4개 최소, **6개 권장**.

1. **대응점 찍기** 켜기 (점군이 없으면 자동 로딩)
2. 한 쌍마다: **스캔 점군(또는 스캔 GLB) 먼저** → **모델에서 같은 물리 위치**
3. 찍을 곳: 엘보·T분기·밸브·배관 끝처럼 **뚜렷한 점**. 멀리 퍼뜨린다
4. 하지 말 것: 직선 배관 위 점 4개(collinear → red), 서로 가까운 점만
5. 개수가 4 이상이면 **정합 저장**
6. 정합 품질이 **green**이면 그대로 coverage 분석. **yellow**는 검수 전제. **red**면 분석해도 observed 승격 금지 → 점 보강
7. residual이 큰 쌍은 **마지막 삭제** 후 다시

leave-one-out이 흔들리면 그 한 점이 틀린 것이다. 스케일이 안 맞으면 점이 한 구역에 몰린 경우가 많다.

## C. coplay 위치 지정 (경로만 손으로 보정)

`/coplay?upload=upload_1781521406685` 하단 **위치 지정**:

- 모델 클릭 = 첫 위치
- 화살표 이동 · `[` / `]` 회전 · `,` / `.` 스케일 · `m` 좌우반전 · PgUp/Dn 높이

이건 데모 경로 안착용이다. 여기서 맞았다고 coverage가 자동 확정되지 않는다. 실적에 쓰려면 A 또는 B로 `/coverage`에 다시 저장한다.

## 실적 등록까지

정합 저장 ≠ 시공 완료.

1. coverage 분석 → 부재 색칠은 **촬영 evidence**
2. 90% 리포트가 “수동 검수 필요”면 객체 클릭 → 프레임 확인
3. **검수 기록**에 수락/메모. 자동 `observed`를 원장 확정으로 쓰지 않음
4. 천장만 찍힌 부재는 화면 밖 앵커가 많아 `not_observed`가 정상일 수 있다 (미시공이 아님)
