현장 영상 ↔ IFC 설계모델 자동 매핑

단안 점군 재구성을 설계 BIM 위에 위치·회전·스케일 자동 정합하는 방법 검토

현장 영상에서 만든 점군은 up-to-scale(비metric)이고 모델은 반복적인 MEP 골격뿐이라 자동 정합이 모호합니다. 본 보고서는 오픈소스 기법을 조사·비교하고, 메트릭화 → 구조 셸 global registration → 시맨틱 검증 → ICP → 설계-대-실제 coverage로 이어지는 자동 매핑 파이프라인을 제안합니다.

Problem

1. 문제 재구성 — 왜 자동으로 안 맞나

현재 방식의 한계를 자유도(scale·rotation·translation) 관점에서 정의하면 해법 구조가 보입니다.

세 가지 실패 모드

  • 스케일(거리) — 재구성 모델은 상대 깊이만 출력(메트릭 헤드 없음). 스캔의 "경로 26m"는 임의 단위. 자동배치는 scale=1.0 고정이라 어디 놓아도 크기가 안 맞음.
  • 위치/방향 — 동일 배관 166개가 반복 → 기하만으론 전역 위치·yaw 결정 불가(다중 해).
  • 매칭 대상 부족 — 영상은 방 전체(벽·바닥·기둥·조명)를 재구성하나 모델은 배관/덕트만 → 대다수 점이 out_of_scope 클러터.
핵심 재구성 (reframe)

문헌·오픈소스가 가리키는 정답 구조: (A) 재구성을 먼저 metric으로 만들고 → (B) 비반복 "구조 셸"에 global registration → (C) 시맨틱 검증 → (D) ICP 미세정합 → (E) 설계-대-실제 coverage. 즉 "scale=1.0 + 반복 MEP 기하 탐색"을 "메트릭화 + 구조 셸 정합 + 시맨틱"으로 교체.

Landscape

2. 오픈소스 / 기법 랜드스케이프

카테고리별로 즉시 사용 가능한 오픈소스와 최신 논문을 정리했습니다.

IFC 수집 (geometry + 속성)

  • IfcOpenShell LGPL-3.0 — geom iterator(멀티CPU)로 요소별 mesh + Pset/IfcType/층 추출. 표준·성숙. docs · 예제

단안 스케일 복원 (우리 핵심 결손)

  • Metric3D v2 — zero-shot metric depth/normal, 벤치 1위. 키프레임에 적용해 재구성을 실측 스케일로 보정. arxiv
  • UniDepth (CVPR 2024) — universal metric depth.
  • 고전: 지면+카메라 높이, 알려진 기준 길이/피두셜, IMU. ground-plane scale

Global registration (coarse · 부분겹침 · 스케일)

  • TEASER++ MIT (T-RO 2020) — 유사변환(scale+R+t) 동시 해, 아웃라이어/저겹침에 강함(≈10%까지), 초기추정 불필요. 시공중 부분겹침에 최적. repo · paper
  • Open3D MIT — RANSAC+FPFH / Fast Global Registration + point-to-plane ICP, 즉시 Python. global reg

학습기반 저겹침 정합 (기하 풍부할 때)

  • Predator / OverlapPredator (CVPR 2021, 저겹침), GeoTransformer (CVPR 2022), CoFiNet, Lepard — 코드 공개. 목록 (라이선스 확인 필요)

Scan-to-BIM / 설계-대-실제 (도메인 · 최신)

  • Cloud2BIM (오픈소스) — 점군→IFC 생성(벽/슬래브/개구부). arxiv 2503.11498
  • as-built↔as-designed: 가시성맵 + 비전 파운데이션 특징 하이브리드 → 실제 현장 92% 성공 (AiC 2025). link
  • Global BIM-point 정합+연관 (distance field, coarse-to-fine, AiC 2024). link
  • IFC 기반 진척 모니터링 (MDPI Buildings 2022). link

읽는 법

TEASER++는 스케일·부분겹침에서 최고이나 반복기하 단독으로는 약함 → 시맨틱·구조 셸과 결합해야 함. Metric3D는 정합기법이 아니라 스케일 전처리로 별도 축에서 기여(레이더에는 미포함).

Pipeline

4. 권장 자동 매핑 파이프라인

6단계. 단안 스케일을 먼저 제거하고, 비반복 구조물에 정합한 뒤 시맨틱으로 검증합니다.

flowchart LR A[0. 스케일 메트릭화
Metric3D v2 / 기준길이] --> B[1. IFC 수집
IfcOpenShell · 요소+Pset] B --> C[2. 구조 셸 타깃
Wall/Slab/Column · 바닥평면] C --> D[3. Coarse 정합
TEASER++ / Open3D FGR] D --> E[4. 시맨틱 검증
IfcType 인라이어 · 다중가설] E --> F[5. Fine ICP
point-to-plane] F --> G[6. 설계-대-실제
coverage · 진척/편차] 
0. 스케일 메트릭화 : Metric3D v2/UniDepth로 키프레임 metric depth → 글로벌 scale 보정
                     (또는 알려진 기준 길이 1개). → scale 미지수 제거
1. IFC 수집        : IfcOpenShell → 요소별 mesh+Pset+층/계통, 좌표 정규화(측량좌표·단위·up축)
2. 타깃 선택       : 구조 셸(Wall/Slab/Column)만 정합 타깃 = 비반복·조기시공·안정
                     스캔 바닥평면 검출 → Z+2회전 고정(→ 4-DoF: x,y,yaw[,scale])
3. Coarse 정합     : TEASER++ (FPFH 대응) — 부분겹침·잔여 scale. 대안 Open3D FGR
4. 시맨틱 검증     : IfcType 일치 인라이어 채점 + 다중가설 top-K, 동률이면 1앵커 tiebreak
5. Fine ICP        : point-to-plane (Open3D) 최종 스냅
6. 설계-대-실제    : 요소별 occupancy → observed/missing/편차 (현 coverage 분석)
Scale

5. 단안 스케일 복원 (가장 큰 결손)

재구성이 비metric인 한 어떤 정합도 거리가 안 맞습니다. 스케일을 먼저 고정하는 것이 핵심.

  • 선처리 메트릭화 (권장) — Metric3D v2 / UniDepth로 키프레임 metric depth 추정 → 재구성을 실측 스케일로. registration이 rigid가 되어 훨씬 강건.
  • 현장 기준 — 알려진 길이 1개(두 점 + 실측 거리), 또는 피두셜(AprilTag) 1개.
  • 정합 동시 추정 — TEASER++ 유사변환 모드로 잔여 scale을 정합 중 재추정.
현재 임시방편

지금의 "scale 9종 탐색"은 휴리스틱이며, 실측에서 scale≈1.0이 최적으로 뽑힌 건 이 재구성이 우연히 거의 metric이기 때문입니다. 일반화하려면 메트릭화 단계로 대체 권장.

As-built

6. 설계-대-실제 / 시공 진행중

시공중에는 실제(영상)와 설계가 다릅니다. 부분 겹침을 견디고, 안정 기준물에 정합해야 합니다.

  • 조기 시공된 구조물에 정합 — 기둥·슬래브·벽은 먼저 시공되고 비반복적 → 안정 앵커. 배관은 늦게 설치되므로 배관-only 모델은 초기 현장에서 약함.
  • 부분 겹침 강건 — TEASER++/Predator는 미시공 구역이 있어도 정합을 깨지 않음.
  • 정합 후 가치 — 요소별 coverage = 진척/시공검증, 편차 = tolerance 초과 거리. 현 coverage 분석이 이미 observed/not_observed 산출 → 토대 존재.
전제

사용자가 IFC로 구조 전체를 받을 예정 = "구조 셸에 정합" 전제가 충족됩니다. 이것이 자동화·시공중 안정성의 결정적 인에이블러.

Apply & Sources

7. lingbot-map 적용 · 다음 단계 · 출처

현 스택(Python · Open3D · scipy · IFC 예정)과 호환되는 구체 실행 계획입니다.

레포 적용 다음 단계

  • IfcOpenShell 수집 경로 추가 — 현 GLB-native 객체모델과 동형으로 IFC → 요소 + Pset 매핑.
  • 메트릭 스케일 단계 추가 — Metric3D v2로 재구성 재스케일 → scale=1.0/9종탐색 hack 제거. 또는 "두 점 + 실측거리" 캘리브 노출.
  • 그리드 탐색 → TEASER++ / Open3D FGR 교체 — 구조 셸 타깃, FPFH 대응.
  • 검증·coverage 유지 — green/yellow/red + 요소별 coverage(이미 설계-대-실제 비교기).
  • 구조/건축 IFC 적재 — 자동화의 결정적 인에이블러.
한 줄 요약

자동 매핑의 핵심 = (1) 메트릭화(Metric3D v2) + (2) 비반복 구조 셸에 TEASER++ global registration + (3) IfcOpenShell 시맨틱 + ICP. 모두 오픈소스이며 현 스택과 호환. PoC 우선순위: IfcOpenShell 수집 + Metric3D 스케일.
